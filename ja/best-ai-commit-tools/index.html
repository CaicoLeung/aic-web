ベストな AI コミットメッセージツール

git diff を読んでコミットメッセージを起草する CLI はいくらでもあります。「どれがベスト？」への正直な答えは「何が欲しいかによる」です。以下は公正で、機能を検証したツールの調査 — と、素早く選ぶ方法です。

開示。aic は私たちのツールなので、このリストに含まれています。各ツールが本当に得意なことについて、紹介文をすべて正直に保ちました — 他が私たちに勝つ点も含めて。

選び方

  • 未ステージの作業を論理的なコミットに分割したい — 1つのファイル内でも → aic
  • マージコンフリクトを解決してほしい、後でメッセージだけでなく → aic
  • 人気でサポートの良いデフォルトが欲しい → aicommits
  • ハッカソン優勝で、設定可能な GitMoji を持つ高機能ラッパーが欲しい → OpenCommit
  • すでに Claude Code で働いている → ai-commit
  • 無料、ローカル、オフラインがいい — PR の説明も → git-ai
  • 最多のプロバイダと洗練された TUI が欲しい → llmc

顔ぶれ

  • aic

    私たちです

    Rust · brew / installer

    新機能 · v0.3.5

    1つのファイル、複数のコミット

    hunk ごとの分割 — ここでファイル境界より下に行く唯一のツール。

    ここで唯一、未ステージの作業を hunk レベルで論理的なコミットに分割するツール — だから1つのファイルでも複数の焦点を絞ったコミットになり得る — そしてマージコンフリクトを解決します（`aic resolve`）。依存関係のない Rust バイナリとして出荷し、Anthropic、Gemini、DeepSeek をファーストクラスでサポートします。

    aicommits と比較 →

  • aicommits

    Node.js · npm

    定着したデフォルト — prepare-commit-msg フック、gitmoji サポート、最大のコミュニティ、そして OpenRouter 経由で任意のモデル。

    リポジトリ ↗ 完全な比較 →

  • OpenCommit

    Node.js · npm

    GitHub 2023 ハッカソン優勝 — 設定可能な GitMoji、ローカル Ollama/llama.cpp、そして巨大なコミュニティ（7.5k★、約12k npm ダウンロード/月）を持つ高機能ラッパー。

    リポジトリ ↗ 完全な比較 →

  • ai-commit

    Node.js · brew / npm

    ソースファイルを読む Claude Code プロバイダで際立ちます — すでに Claude Code を使っているならぴったりです。

    リポジトリ ↗ 完全な比較 →

  • git-ai

    Node.js · npm / npx

    デフォルトでローカル Ollama（無料、オフライン）で、コミットメッセージだけでなく PR の説明も起草します。

    リポジトリ ↗ 完全な比較 →

  • llmc

    Node.js · npx / npm

    最も広いプロバイダリスト（13）に、洗練されたターミナル UI、TOML 設定、カスタムプロンプト、自動コミット。

    リポジトリ ↗ 完全な比較 →

網羅ではありません — 空間は混み合っています（commitizen、cz-git など十数個追加で）。この6つは異なるアプローチをカバーします：自動バッチ、既存の大手、Claude Code ネイティブ、ローカルファースト、最多プロバイダ、そしてハッカソン優勝の高機能 CLI。

私たちの正直な見解

作業が未ステージで溜まり、クリーンでアトミック、コンベンショナルなコミットとしてコミットしたい — しかも Node.js をインストールせずに — なら aic はそのために作られています。そうでなければ、aicommits が安全なデフォルトのままで、他はそれぞれ明確なニッチを占めます。
