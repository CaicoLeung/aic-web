用 DeepSeek 写提交信息

DeepSeek 是 aic 的一流供应商:在配置向导里选中它、粘贴你的密钥,aic 就会读取你的 diff 并写出一条约定式提交——一条命令搞定。你的密钥永远不会离开你的机器,而且 aic 能做的一切——自动分批、aic resolve、无需 Node.js——在 DeepSeek 上同样可用。

为什么选择 DeepSeek + aic

  • 一流供应商——无需 OpenRouter 中转或自定义端点
  • 又快又便宜——aic 默认使用为提交信息调优的轻量模型
  • 没有中间商——调用直接从你的机器发往 DeepSeek
  • 功能完全一致——自动分批和 `aic resolve` 在所有供应商上都能用

一个向导搞定配置

  1. 运行 aic setup
  2. 选择 DeepSeek 作为供应商
  3. 粘贴你的 DEEPSEEK_API_KEY 并选择模型
  4. 提交——暂存你的工作并运行 aic

设置 LLM_BACKEND=deepseek 和 DEEPSEEK_API_KEY,然后运行 aic。配置按 环境变量 → 配置文件 → 默认值 的顺序解析。

默认模型

aic 内置合理的 DeepSeek 默认模型(deepseek-v4-flash)——针对提交信息这类轻量任务,又快又便宜。随时可用 LLM_MODEL 覆盖。

常见问题

aic 支持 DeepSeek 吗？

支持——DeepSeek 是 aic 的一流供应商,与 OpenAI、Anthropic、Gemini 及其他 7 家并列。

aic 用哪个 DeepSeek 模型？

aic 默认使用 deepseek-v4-flash——针对提交信息调优的快速、低成本模型。随时可用 LLM_MODEL 覆盖。

我的 DeepSeek 密钥安全吗？

安全——aic 直接从你的机器调用 DeepSeek。密钥永远不会离开你的机器,没有中间商,也没有按次计费加成。
