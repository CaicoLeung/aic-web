DeepSeek로 커밋 메시지 작성

DeepSeek은 aic의 일급 프로바이더입니다: 설정 마법사에서 선택하고 키를 붙여넣으면 aic가 diff를 읽고 conventional 커밋을 작성합니다 — 명령 하나. 키는 기기를 떠나지 않습니다. aic가 하는 모든 것 — 자동 배칭, aic resolve, Node.js 불필요 — 은 DeepSeek에서도 그대로 동작합니다.

DeepSeek + aic를 선택하는 이유

  • 일급 프로바이더 — OpenRouter 경유나 커스텀 엔드포인트 불필요
  • 빠르고 저렴 — 커밋 메시지에 맞게 조정된 경량 모델을 기본으로
  • 중간자 없음 — 기기에서 DeepSeek으로 직접 호출
  • 전 기능 지원 — 자동 배칭과 `aic resolve`는 모든 프로바이더에서 동작

하나의 마법사로 설정

  1. aic setup 실행
  2. 프로바이더로 DeepSeek 선택
  3. DEEPSEEK_API_KEY 붙여넣기 및 모델 선택
  4. 커밋 — 작업을 스테이징하고 aic 실행

LLM_BACKEND=deepseek와 DEEPSEEK_API_KEY를 설정하고 aic를 실행하세요. 설정은 환경 변수 → 설정 파일 → 기본값 순으로 결정됩니다.

기본 모델

aic는 합리적인 DeepSeek 기본값(deepseek-v4-flash)을 내장합니다 — 커밋 메시지 작업에 빠르고 저렴합니다. 언제든 LLM_MODEL로 덮어쓸 수 있습니다.

자주 묻는 질문

aic는 DeepSeek를 지원하나요?

네 — DeepSeek는 OpenAI, Anthropic, Gemini 등 7개 이상과 함께 aic의 일급 프로바이더입니다.

aic는 어떤 DeepSeek 모델을 사용하나요?

aic는 기본적으로 deepseek-v4-flash — 커밋 메시지에 맞는 빠르고 저렴한 모델을 사용합니다. 언제든 LLM_MODEL로 변경할 수 있습니다.

제 DeepSeek 키는 안전한가요?

네 — aic는 기기에서 DeepSeek으로 직접 호출합니다. 키가 기기를 떠나지 않으며 중간자나 커밋당 과금도 없습니다.
