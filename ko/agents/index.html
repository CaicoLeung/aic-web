기능 · CLI 에이전트 백엔드

에이전트를 가져오세요, 키가 아닙니다.

aic는 헤드리스 모드에서 로컬 AI 코딩 에이전트 — Claude Code, Codex, Cursor, Gemini 등 11개 프리셋 — 에 작업을 위임할 수 있습니다. API 키도, 기본 모델도, 중간자도 없음: 에이전트가 diff를 읽고 커밋을 작성하며, 자신의 모델과 인증을 재사용합니다.

→ 그런 다음 aic setup 실행 → 에이전트 백엔드 선택

작동 방식

같은 루프, 다른 백엔드. LLM API를 호출하는 대신, aic는 프린트 모드에서 에이전트를 실행하고 diff를 전달하며, 에이전트가 가장 잘하는 일 — 변경 사항을 추론하고 메시지를 작성하는 일 — 을 맡깁니다.

  1. 에이전트 백엔드 선택 aic setup을 실행하고 API 프로바이더 대신 CLI 에이전트를 선택하세요. aic가 기억합니다.
  2. 호출이 아닌 위임 aic를 실행하면 diff와 프롬프트와 함께 에이전트 — 예: claude -p — 로 위임합니다. 추론은 에이전트가 합니다.
  3. 동일한 커밋 결과 에이전트가 메시지를 반환합니다. aic가 git 히스토리에 적용합니다 — 배치, 컨벤셔널, 컬러, 언제나처럼.

11개 에이전트, 하나의 백엔드

11개 프리셋이 기본 제공 — 3개는 추론을 실시간 스트리밍, 8개는 프린트 모드로 동작. 각각 자체 인증을 재사용 — 에이전트가 이미 설치되어 있다면 추가 설정 불필요.

  • Claude Code thinking_delta로 추론을 실시간 스트리밍. 에이전트가 생각하는 것을 지켜본 뒤 커밋하세요.
  • Codex 읽기 전용 샌드박스에서 조용히 실행, 완료되면 메시지를 반환합니다.
  • Pi 토큰 단위로 추론을 실시간 스트리밍 — Claude Code의 페이즈 끝 일괄 출력보다 세밀.
  • OpenCode 조용히 실행, 기존 프로바이더 키(예: Cursor OAuth)를 재사용.
  • Oh My Pi pi 포크 — pi처럼 추론을 실시간 스트리밍.
  • Gemini gemini -p 프린트 모드. 이 프리셋은 같은 이름의 프로바이더를 가립니다 — aic use google으로 Google API를 계속 사용 가능.
  • Cursor cursor-agent -p 프린트 모드. 신뢰 없이 실행 — 쓰기는 비활성화.
  • Windsurf Windsurf는 Devin Desktop으로 개명 — 프리셋은 devin 바이너리에 매핑.
  • GitHub Copilot 프린트 모드. 도구 사용은 대화형 승인이 필요해 헤드리스 실행은 텍스트 전용.
  • Trae traecli -p 프린트 모드 — 읽기 외 도구는 프롬프트로 제한.
  • Qwen Code gemini-cli 계열 — qwen -p 프린트 모드.

백엔드를 전환하세요 — 둘 다 실행하지 마세요

backend_kind는 구분자입니다: 실행마다 하나의 백엔드만 활성화됩니다. API 경로(provider · key · model)와 에이전트 경로(로컬 CLI)는 레이어가 아니라 대안입니다.

전환하려면 aic setup을 다시 실행하세요. aic는 하나의 구성을 저장 — 마지막으로 선택한 백엔드가 사용됩니다.

또는 모든 커스텀 에이전트

11개 프리셋 외에도, 모든 CLI 명령을 에이전트로 구성할 수 있습니다. stdin으로 프롬프트를 받고 stdout으로 출력한다면, aic가 구동할 수 있습니다.

왜 빠른가

API 홉도, 새 인증도 없습니다. 에이전트는 이미 모델을 로드하고 인증을 마친 상태 — aic는 diff를 전달하고 메시지를 읽어올 뿐.

속도는 더 빠른 모델이 아니라 설정 생략에서 옵니다. 에이전트의 세션과 자격 증명을 재사용하는 것입니다.

짧은 요약

aic + 코딩 에이전트: 에이전트는 추론, aic는 커밋을 출시. API 키도, 중간자도, 고를 모델도 없음 — aic가 언제나 만드는 것과 같은 배치된, 컨벤셔널, 컬러 히스토리뿐.
