01 — 소개

+ 그만 쓰자, 커밋 메시지. + 그만 풀자, 병합 충돌.

히스토리가 "fix stuff"와 "WIP"뿐이어선 안 됩니다. aic는 diff를 읽고 진짜 conventional 커밋을 작성해 보냅니다 — 명령 한 번. 병합 중이라면, 깔끔한 해결책을 제안합니다 — 파일마다, 당신이 diff를 승인하기 전에는 아무것도 적용되지 않습니다. 스테이징 없음? 한 파일을 여러 집중 커밋으로 자동 분할합니다.

aic 설치 — 명령 하나 → 그런 다음 aic setup 실행

  2. 02

  5. 05

  6. 06

03 — 자동 배치

스테이지된 게 없어?

한 파일, 여러 커밋

aic는 hunk 단위로 diff를 읽습니다 — 그래서 한 파일도 여러 개의 집중된 커밋이 될 수 있고, 각각 하나의 아이디어. 스테이지 없이, 명령 한 번, 깔끔한 히스토리 — 한 파일이 세 가지 관심사에 걸쳐 있어도.

05 — 설치

한 줄로 aic 설치.

  • 무료 & MIT
  • Node.js 불필요
  • 12개 프로바이더
  • pre-commit 훅과 공존
  • 키는 기기를 떠나지 않음
brew install CaicoLeung/aic/aic

`brew upgrade aic`로 업데이트. Homebrew 설치는 자동 감지되어 `aic update`가 brew로 안내합니다.

curl --proto '=https' --tlsv1.2 -sSfL https://github.com/CaicoLeung/aic/releases/latest/download/aic-installer.sh | sh
