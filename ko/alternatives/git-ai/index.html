git-ai 대안: aic

git-ai는 로컬 우선 Git 어시스턴트입니다 — 커밋, PR 설명, 설정 없는 Ollama. 초기 단계(v0.1.3)이고 2026년 2월부터 휴면 상태입니다. 원자적 히스토리라면 aic가 대안이고, 매주 릴리스합니다.

git-ai에서 전환하는 이유

git-ai는 파일 단위이고 몇 달째 업데이트가 없습니다 — PR 설명 기능 외에는 분할도 해결도 할 수 없습니다.

기능별 비교

기능 aic git-ai
스테이징되지 않은 작업을 여러 커밋으로 자동 배칭 ✓ 예 — 스테이징되지 않은 변경을 논리적 원자 커밋으로 분할 ✗ 아니요 — 스테이징된 diff당 메시지 하나
단일 파일을 여러 커밋으로 분할(per-hunk) ✓ 예 — 각 hunk를 의도에 따라 자신의 커밋으로 ✗ 아니요 — 기껏해야 파일 단위
머지 충돌 해결 ✓ 예 — `aic resolve`가 diff를 제안하고 파일별로 확인 ✗ 아니요 — 커밋 메시지만
PR 설명 ✗ 아니요 ✓ 예 — `git ai pr`
로컬 우선 기본값 원하는 프로바이더 선택(Ollama 포함) 설정 없는 Ollama — 무료·오프라인
런타임과 의존성 Rust 바이너리 — Node.js 불필요 Node.js ≥ 22 — npm / npx
설치·설정 대화형 `aic setup` 마법사 `git ai config` 명령
프로바이더 범위 11개 일급 + OpenAI 호환 Ollama, OpenAI, Anthropic
프로젝트 활동 매주 릴리스 2026-02 이후 조용
커밋 메시지 형식 Conventional Commits conventional + gitmoji 옵션
여러 메시지 후보 아니요 아니요

전환 방법

  1. aic 설치: brew install CaicoLeung/aic/aic
  2. 한 번만 설정: `aic setup` 실행 — 프로바이더·키·모델을 하나의 마법사에서
  3. 커밋: 작업을 스테이징하고 `aic` 실행; aic가 스테이징하지 않은 작업을 자동으로 배칭합니다
